## Title

**Self-Serve Enterprise File Transfer on AWS**

## Subtitle

Build governed, API-driven B2B file transfer platforms with AWS Transfer Family, automation, and self-service control planes.

## Category

Cloud Computing · AWS · Enterprise Integration · DevOps

## Level

Intermediate

## Duration

8 weeks · 48–64 hours total effort

## Short description (150 words)

Move beyond legacy MFT appliances. In this BayLearn Academy program by BayAreaLa8s, you will design and implement enterprise-grade file transfer on AWS—from SFTP landing zones and KMS-secured S3 buckets to Lambda and Step Functions automation, Transfer Family connectors, and Cognito-backed self-serve APIs. Each week includes hands-on labs with rubrics; the program culminates in a capstone architecture and demo you can present to architects and security stakeholders. Aligned to real-world self-serve and orchestration patterns used in enterprise workshops. Prerequisites: AWS fundamentals and IAM/S3 experience.

## Learning outcomes (bullet list for LMS)

- Design enterprise file-transfer architectures on AWS  
- Deploy and secure AWS Transfer Family (SFTP) with S3  
- Automate validation and routing with Lambda and EventBridge  
- Orchestrate transfers with Step Functions and idempotency  
- Implement connector-based S3 ↔ SFTP flows  
- Build self-serve connection catalogs and job APIs  
- Operate with CloudWatch dashboards, alarms, and runbooks  
- Deliver a capstone demo and architecture package
