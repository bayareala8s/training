# Self-Serve Enterprise File Transfer on AWS

**BayLearn Academy · by BayAreaLa8s**

---

## Transform B2B file exchange for the cloud era

Enterprises still move **billions of files** via SFTP and batch pipelines—but legacy MFT appliances are costly, slow to change, and invisible to modern DevOps. This **8-week, hands-on program** teaches your teams to build **governed, self-service file transfer platforms** on AWS using Transfer Family, S3, automation, and API-first control planes.

---

## Who it's for

Cloud engineers · Solutions architects · Integration/MFT specialists · Platform & DevOps teams

**Prerequisites:** AWS fundamentals, IAM, S3 comfort

---

## What you'll build

- Production-style **SFTP → S3** landing zones  
- **Security baseline** (KMS, IAM, audit)  
- **Event-driven** validation and routing  
- **Step Functions** orchestration with idempotency  
- **SFTP connectors** for partner delivery  
- **Self-serve APIs** (Cognito + API Gateway)  
- **Capstone** you can show in portfolio and internal pitches
