# Week 7 — Operations, reliability & cost

> **Full module content:** **[Module 7 — Operations, reliability & cost](../modules/week-07.md)**

## Learning objectives

- Build CloudWatch dashboards for transfers and workflows.
- Define alarms: failures, duration SLAs, Transfer server health.
- Write an operations runbook: onboarding, incident, rollback.
- Estimate cost drivers and optimization levers.

## Topics

1. SLOs for file transfer: latency, success rate, completeness  
2. Structured logging and correlation IDs  
3. DR: multi-AZ, cross-region replication (conceptual)  
4. Cost: Transfer hourly, data transfer, Step Functions transitions  
5. Game day: failure injection exercise
