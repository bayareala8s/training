# Module 05 — Cloud and Platform Strategy

**Week:** 5  
**Duration:** 2-hour live session + AWS lab/assignment  
**Case study:** NorthStar Financial Services (fictional)  
**Student role:** Lead Enterprise Architect  
**Lab:** [Design and Deploy a Low-Cost Enterprise Platform Foundation](../../labs/lab-05-cloud-platform-foundation/student-instructions.md)

---

## Module objective

Define a credible cloud and platform strategy for NorthStar—including landing-zone concepts, shared platform capabilities, build-versus-buy decisions, and FinOps guardrails—then deploy a low-cost AWS platform foundation that demonstrates those principles.

---

## Learning objectives

Students will be able to:

1. Define cloud and platform strategies including landing zones, shared services, and guardrails (CLO 13).
2. Distinguish build-versus-buy decisions for platform capabilities and document them as ADRs (CLO 14).
3. Apply FinOps practices: tagging, budgets, cost allocation, and service lifecycle controls (CLO 15).
4. Communicate platform trade-offs to executives and platform engineering leaders.

Full detail: [`learning-objectives.md`](learning-objectives.md)
