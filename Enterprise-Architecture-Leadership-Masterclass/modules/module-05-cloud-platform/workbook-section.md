# Workbook — Module 05: Cloud and Platform Strategy

**Case study:** NorthStar Financial Services (fictional)

## Exercises

1. **Posture statement (5 sentences):** Write NorthStar’s cloud posture for the next 24 months.
2. **Landing-zone sketch:** Draw OUs/accounts and label owners for security/audit, shared services, workloads, sandbox.
3. **Capability map:** Complete `student/templates/21-platform-capability-map.md` for at least eight capabilities.
4. **Build-vs-buy:** Score one capability using `17-build-versus-buy.md`, then draft ADR-M05-01.
5. **FinOps policy:** Write tagging rules, budget thresholds, and sandbox expiration policy (1 page).
6. **Lab reflection:** What control in the AWS foundation most improves executive trust—and why?
