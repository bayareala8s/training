# Prerequisites — Module 05

## Course prerequisites

- Modules 01–04 concepts: EA role, capabilities, current state, target-state / roadmap thinking
- Familiarity with NorthStar fictional case study baseline

## Technical prerequisites (AWS lab)

| Requirement | Notes |
| ----------- | ----- |
| AWS account | Sandbox / personal training account preferred |
| IAM permissions | IAM, S3, CloudTrail, DynamoDB, Lambda, API Gateway, SSM, Budgets, CloudWatch Logs |
| Terraform | >= 1.5 installed locally |
| AWS CLI | v2 configured; `aws sts get-caller-identity` works |
| Budget alert email | Valid email you can confirm |

## Knowledge prerequisites

- Basic AWS service literacy (S3, IAM, Lambda)
- Comfort reading Terraform HCL at overview level (you do not need to author from scratch)

## Cost and safety

- Estimated lab cost **~<$5** if destroyed same day
- Do **not** enable optional AWS Config unless stretch and you accept cost risk
- Never use production data or production accounts
