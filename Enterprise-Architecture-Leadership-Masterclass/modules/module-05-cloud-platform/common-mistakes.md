# Common Mistakes — Module 05

1. **Confusing accounts with a landing zone** — Accounts without guardrails and ownership are sprawl.
2. **Multi-cloud as default** — Without dual platforms and skills funding, it multiplies cost.
3. **Platform built for architects, not engineers** — Golden paths need adoption metrics.
4. **Build everything** — Commodity controls (audit trail, budgets) should rarely be custom.
5. **FinOps after the bill shock** — Tags and budgets must precede migration waves.
6. **Leaving lab resources running** — Undermines the FinOps lesson; always destroy.
7. **Enabling AWS Config casually** — Optional stretch only; ongoing cost.
8. **Strategy with no trade-off table** — Executives need alternatives and risks, not slogans.
