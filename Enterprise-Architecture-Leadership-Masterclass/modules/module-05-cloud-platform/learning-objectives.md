# Learning Objectives — Module 05

**Module:** Cloud and Platform Strategy  
**Mapped course LOs:** 13, 14, 15

---

## Primary objectives

| ID | Objective | Bloom | Assessment |
| -- | --------- | ----- | ---------- |
| M5-LO1 | Articulate a cloud strategy for NorthStar covering posture, principles, and workload placement | Apply | Lab + assignment |
| M5-LO2 | Design a conceptual landing zone and platform capability map with clear ownership | Create | Lab deliverables |
| M5-LO3 | Complete a build-versus-buy assessment and ADR for a platform capability | Evaluate | Assignment ADR |
| M5-LO4 | Implement FinOps controls (tags, budget, lifecycle) in a live AWS foundation | Apply | Lab validation |
| M5-LO5 | Explain cost, security, and operability trade-offs of platform choices to leaders | Analyze | Quiz + debrief |

## Success criteria

By end of week 5, students can defend why NorthStar needs a shared platform foundation *before* accelerating workload migration—and show a working, cleaned-up AWS proof of those controls.
