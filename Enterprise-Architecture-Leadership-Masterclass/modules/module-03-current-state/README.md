# Module 03 — Current-State Architecture Assessment

**Week:** 3  
**Duration:** 2-hour live session + lab/assignment  
**Case study:** NorthStar Financial Services (fictional)  
**Student role:** Lead Enterprise Architect

---

## Module objective

Assess NorthStar’s current technology estate with a manageable, decision-oriented approach—using discovery techniques, TIME / application portfolio management, dependency insight, and a ranked view of risk and technical debt—without producing an unusable inventory dump.

---

## Learning objectives

Students will be able to:

1. Plan discovery that balances speed, confidence, and stakeholder load.
2. Apply TIME (Tolerate, Invest, Migrate, Eliminate) with explicit scoring rationale.
3. Map critical dependencies and concentration risks across the portfolio.
4. Produce a top-risk / technical-debt narrative executives can act on.

Full detail: [`learning-objectives.md`](learning-objectives.md)
