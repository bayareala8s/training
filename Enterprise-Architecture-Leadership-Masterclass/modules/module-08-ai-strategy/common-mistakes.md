# Common Mistakes — Module 08

1. Treating free-text chat as an operational decision system
2. No schema validation before persistence
3. HITL flag with no staffing model
4. Logging raw PII prompts
5. Skipping evaluation (“it looked good in the demo”)
6. Ignoring token/cost telemetry
7. Failing the lab because Bedrock access was blocked—instead of using documented mock mode
8. Leaving API Gateway/Lambda deployed without cleanup
