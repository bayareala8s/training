# LinkedIn Promo — Module 08

AI strategy fails when demos outrun governance.

Module 08 of the Enterprise Architecture Leadership Masterclass (BayLearn) puts architects in the NorthStar Financial Services (fictional) case to design a governed incident decision assistant:

- Use-case scoring with explicit go/no-go  
- Structured JSON outputs, validation, and deterministic rules  
- Human-in-the-loop routing for high-risk decisions  
- Token/cost tracking and evaluation datasets  
- AWS Bedrock lab with a documented mock fallback if model access is not enabled  

Architecture leadership for AI is about outcomes, controls, and operability—not model hype.
