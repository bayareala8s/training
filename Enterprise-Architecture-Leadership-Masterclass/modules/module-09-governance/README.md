# Module 09 — Architecture Governance and Executive Communication

**Week:** 9  
**Duration:** 2-hour live session + ARB simulation lab/assignment  
**Case study:** NorthStar Financial Services (fictional)  
**Student role:** Lead Enterprise Architect (and rotating ARB roles)  
**Slug:** `module-09-governance`

---

## Module objective

Establish NorthStar’s architecture governance operating model—standards, guardrails, exceptions, and Architecture Review Board (ARB)—and practice executive-ready challenge of a divergent business-unit proposal using ADRs and decision memos.

---

## Learning objectives

Students will be able to:

1. Design an architecture governance model that balances speed with enterprise risk control.
2. Facilitate an Architecture Review Board using role-based challenge and decision criteria.
3. Write Architecture Decision Records (ADRs) with context, alternatives, and consequences.
4. Communicate architecture recommendations to executives in business language via decision memos.

Full detail: [`learning-objectives.md`](learning-objectives.md)

### Deliverables

- Completed ARB review checklist against the divergent proposal pack
- Role-based challenge notes and recommended disposition (Approve / Approve with conditions / Defer / Reject)
- Executive decision memo + at least two ADRs documenting the board outcome
