# YouTube / Loom Description — Module 09

**Title:** Architecture Governance & Executive Communication | EA Leadership Masterclass Module 09

**Description:**

Learn how to design architecture governance that enables delivery—standards, guardrails, exceptions, and Architecture Review Boards—then practice executive communication with ADRs and decision memos.

In this BayLearn live-cohort module, students facilitate an ARB simulation for NorthStar Financial Services (fictional): a business unit proposes a divergent cloud, database, integration, and production-access approach. Participants practice role-based challenge and produce a defensible disposition.
