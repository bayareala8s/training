# Learning Objectives — Module 09

**Module:** Architecture Governance and Executive Communication  
**Course outcomes mapped:** LO 25–27 (primary); LO 2–3 (secondary)

---

## Module learning objectives

| ID | Objective | Bloom | Assessment |
| -- | -------- | ----- | ---------- |
| M9-LO1 | Design an architecture governance model combining standards, automated guardrails, exceptions, and review forums appropriate to NorthStar’s scale | Create | Lab + assignment |
| M9-LO2 | Facilitate Architecture Review Board conversations with role fidelity, constructive challenge, and clear disposition criteria | Apply / Evaluate | ARB simulation (participation) |
| M9-LO3 | Author ADRs that document context, options considered, decision, and consequences (including what was not chosen) | Apply | Lab ADRs + assignment |
| M9-LO4 | Produce an executive decision memo that states the ask, business impact, risks, and recommended conditions in non-jargon language | Apply | Lab memo + quiz scenarios |

## Success criteria (student-facing)

By the end of Module 09 you can:

- Explain when light-touch guardrails beat heavy review boards—and when boards are mandatory
- Challenge a divergent proposal without defaulting to “no”
- Leave a durable decision trail (ADR + memo) an auditor or new hire can follow
