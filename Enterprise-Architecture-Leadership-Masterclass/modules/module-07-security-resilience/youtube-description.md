# YouTube / Loom Description — Module 07

**Title:** Module 07 — Security, Risk, Compliance, and Resilience | EA Leadership Masterclass

**Description:**

Week 7 of the Enterprise Architecture Leadership Masterclass (BayLearn / BayAreaLa8s). Students act as Lead Enterprise Architect at NorthStar Financial Services—a fictional instructional case study—and treat security and resilience as first-class architecture concerns.

**In this session**
- Zero Trust and trust-boundary design
- Lightweight STRIDE threat modeling
- RTO/RPO targets and cost-aware DR patterns
- Control-evidence matrices for audit-ready conversations
- AWS lab: IAM, KMS, S3 versioning, CloudWatch, optional replication / simulated DR

**Lab cost warning:** Use serverless patterns only; run the cleanup script after the session. Avoid NAT Gateway, always-on EC2, EKS, and OpenSearch.
