# Learning Objectives — Module 04

**Module:** Target-State Architecture and Transformation Roadmaps  
**Course outcomes mapped:** 10, 11, 12 (see `course-specification/learning-outcomes.md`)  
**Case study:** NorthStar Financial Services (fictional)

---

## Module learning objectives (LOs)

| ID | Learning objective | Bloom level | Primary lesson | Assessment |
| -- | ------------------ | ----------- | -------------- | ---------- |
| LO-4.1 | Define a target-state architecture for NorthStar that aligns strategic capabilities, principles, constraints, and measurable business outcomes. | Create / Evaluate | 4.1 | Lab, Assignment, Quiz |
| LO-4.2 | Select and justify modernization strategies (rehost, replatform, refactor, replace, retire, retain, consolidate) for application and platform groups using TIME-informed trade-offs. | Analyze / Evaluate | 4.2 | Lab, Quiz |
| LO-4.3 | Design at least three transition architectures with coexistence patterns, exit criteria, and risk controls between current and target state. | Create | 4.3 | Lab, Assignment |
| LO-4.4 | Produce a 24-month architecture roadmap that sequences initiatives by value, risk reduction, and dependencies, and communicate it as an executive-ready narrative. | Create / Evaluate | 4.4 | Lab, Assignment, Quiz |

---

## Enabling objectives

Students will also be able to:

- Distinguish target-state aspiration from funded transition commitment.
- Trace roadmap initiatives to NorthStar strategic themes (cost, CX, speed, risk, AI readiness, executive visibility).
- Identify anti-patterns: big-bang rewrite, roadmap-as-project-list, target-state-without-exit-criteria.
- Apply value-versus-risk prioritization when funding is constrained.

---

## Success criteria (observable)

A student who meets Module 04 standards can, without instructor prompting:

1. State NorthStar’s target principles and how they constrain technology choices.
2. Produce an application disposition table (retain / replace / consolidate / retire) with rationale.
3. Describe three named transition states and what “done” means for each.
4. Show a 24-month wave plan with dependencies and value claims executives can challenge.
5. Defend at least one modernization trade-off under ARB-style questioning.
