# Common Mistakes — Module 04

**Module:** Target-State Architecture and Transformation Roadmaps  
**Case study:** NorthStar Financial Services (fictional)

Use this list for self-review before submission and for live debrief.

---

## Target-state mistakes

| Mistake | Why it hurts | Better practice |
| ------- | ------------ | --------------- |
| Vision slide without constraints | Unfundable; loses CFO trust | Include constraints, non-goals, and metrics |
| Target as complete inventory rewrite | Unmaintainable; delays decisions | Pattern-level target + disposition table |
| Ignoring principles | Inconsistent exceptions | Principles with implication + exception test |
| Technology fashion (AI/cloud first) | Misaligned investment | Trace every pattern to a strategic theme |
| No ownership model | Platforms become orphans | Name capability and platform owners |

## Modernization strategy mistakes

| Mistake | Why it hurts | Better practice |
| ------- | ------------ | --------------- |
| “Migrate to cloud” as strategy | Hides disposition choice | Choose rehost/replatform/refactor/replace/etc. |
| Replace everything “legacy” | Dual-run explosion | Retain/replatform cores; replace unfit duplicates |
| Retain all duplicates to keep peace | Permanent cost | Consolidate with survivor ADR |
| Refactor commodity systems | Burns scarce talent | Buy/replace or retire |
| Retire without dependency check | Outage / audit gap | Dependency and data retention plan |

## Transition mistakes

| Mistake | Why it hurts | Better practice |
| ------- | ------------ | --------------- |
| Transitions = project phases only | No architecture content | Name systems of record, interfaces, controls |
| Temporary bridges without end dates | Forever architecture | Exit criteria + retirement milestone |
| Skipping foundation transition | Sprawl during transformation | Transition A = guardrails first |
| Big-bang cutover for payments/onboarding | Unacceptable risk | Strangler + dual-run with thresholds |
| Silent dual-write | Data divergence | Reconciliation metrics as exit criteria |

## Roadmap mistakes

| Mistake | Why it hurts | Better practice |
| ------- | ------------ | --------------- |
| Wish-list roadmap | No sequencing logic | Value, risk, dependencies per phase |
| Everything starts Month 1 | Capacity fiction | Wave capacity and dependency gates |
| Value = “modernization” | Unchallengeable claims | KPI direction per phase |
| Hidden dual-run cost | Budget shock | Show burn-down of coexistence cost |
| No executive ask | No decisions | Explicit decisions, funding, policy needs |

## Leadership / communication mistakes

| Mistake | Why it hurts | Better practice |
| ------- | ------------ | --------------- |
| Jargon-heavy exec summary | Tune-out | Business outcomes first |
| Pretending one “best” path | ARB failure | Trade-off table with consequences |
| Avoiding BU politics | Roadmap stalls | Name winner/loser impacts honestly |
| Lab without assumptions | Ungradeable | Document assumptions explicitly |

---

## Quick pre-submit checklist

- [ ] Fiction notice / NorthStar context present  
- [ ] Strategic capabilities and principles included  
- [ ] Retain/replace/consolidate/retire table completed  
- [ ] Three transition states with exit criteria  
- [ ] 24-month roadmap with dependencies and value per phase  
- [ ] Risks + executive summary  
- [ ] At least one explicit trade-off
