# Module 04 — Target-State Architecture and Transformation Roadmaps

**Week:** 4  
**Duration:** 2-hour live session + lab/assignment  
**Case study:** NorthStar Financial Services (fictional)  
**Student role:** Lead Enterprise Architect  
**Slug:** `module-04-target-state`

---

## Module objective

Design a credible NorthStar target-state architecture, define transition architectures that manage coexistence, and produce a 24-month roadmap that sequences value, risk reduction, and dependencies for executive funding conversations.

---

## Learning objectives

Students will be able to:

1. Define a target-state architecture aligned to business strategy, principles, and constraints.
2. Select modernization strategies (rehost, replatform, refactor, replace, retire, retain, consolidate) with explicit trade-offs.
3. Design transition architectures that manage coexistence between current and target states.
4. Build a sequenced 24-month architecture roadmap with dependencies, value per phase, and risks.

Full detail: [`learning-objectives.md`](learning-objectives.md)
