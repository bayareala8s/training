# Curated Readings — Enterprise Architecture Leadership Masterclass

Non-proprietary, publicly discussable references. Prefer primary sources and reputable publishers. Readings are optional enrichment unless your instructor assigns specific items.

> This list does not reproduce proprietary frameworks or copyrighted book chapters.

---

## Architecture practice and decisions

- Architecture Decision Records — community patterns and examples (search “ADR architecture decision record”)  
- Open Group architecture literature overviews (public TOGAF® materials where freely available; this course is **not** exam prep)  
- Thoughtworks Technology Radar (public) — for technology radar facilitation ideas  

## Platform engineering and golden paths

- Team Topologies (book — purchase if desired; discuss concepts, do not photocopy)  
- Public platform engineering guidance from Cloud Native Computing Foundation (CNCF) and major cloud providers’ architecture centers  

## Cloud and FinOps

- FinOps Foundation public materials (finops.org)  
- AWS Well-Architected Framework (public whitepapers) — principles, not lab copy-paste  
- Azure Architecture Center / Google Cloud Architecture Framework public docs for comparative literacy  

## Security, resilience, and identity

- NIST Cybersecurity Framework (public)  
- NIST SP 800-53 control families overview (public) — for control language literacy  
- CIS Benchmarks overviews (public summaries)  
- Public incident postmortems (e.g., major cloud status reports) for resilience discussions  

## Data and integration

- Public materials on event-driven architecture and API design guidelines from major cloud architecture centers  
- DAMA DMBOK concepts via public summaries (purchase book if desired)  

## AI governance

- NIST AI Risk Management Framework (public)  
- Public responsible AI guidance from major cloud providers  
- OECD AI Principles (public)  

## Communication and leadership

- Executive memo craft — public strategy communication essays from reputable business publications  
- Facilitation guides for architecture reviews (public conference talks / blogs by practitioners)
