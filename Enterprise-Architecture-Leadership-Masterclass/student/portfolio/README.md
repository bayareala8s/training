# Architecture Portfolio Guide

**Course:** Enterprise Architecture Leadership Masterclass  
**Platform:** BayLearn

Use this folder as the index for your professional portfolio assembled from course artifacts.

NorthStar Financial Services is a **fictional** instructional case study. Never present it as a real employer or client engagement.

---

## How to use

1. Complete [`../templates/14-architecture-portfolio-checklist.md`](../templates/14-architecture-portfolio-checklist.md).  
2. Export polished PDFs of your strongest artifacts (memo, roadmap, ADRs, ARB pack, capstone deck).  
3. Write a one-page portfolio narrative linking artifacts to leadership skills.  
4. Keep a public-safe version without account IDs, secrets, or personal data.  
5. Store files locally or in your preferred portfolio repo; this directory is the course pointer and README.

## Recommended portfolio spine (interview order)

1. Executive decision memo (judgment)  
2. One ADR set (decision quality)  
3. Capability map + roadmap (strategy translation)  
4. ARB disposition pack (governance facilitation)  
5. Capstone presentation PDF (executive communication)  
6. Personal leadership plan (growth trajectory)
