## Module-specific interpretation

| Criterion | What “4” looks like this week |
| --------- | ----------------------------- |
| Business alignment | Clear chain from NorthStar themes/KPIs to capability investments |
| Architecture quality | Org/system-independent L1–L2 map; coherent types and owners |
| Trade-off analysis | Explicit sequencing; names deferred work and residual risk |
| Security and resilience | Onboarding includes control-oriented capabilities/stages; no naïve open data sharing |
| Feasibility and roadmap | Respects acquisition coexistence; avoids big-bang rewrite |
| Communication quality | Executive brief scannable; heatmap legend readable |

## Deductions (examples)

- −1 architecture quality if >30% of L1 names are systems/teams
- −1 trade-off if all items are Priority 1
- −1 communication if heatmap has no legend/evidence

## Lab vs assignment

Lab may be slightly incomplete on L2 depth if narrative quality is strong; assignment is expected complete and polished.
