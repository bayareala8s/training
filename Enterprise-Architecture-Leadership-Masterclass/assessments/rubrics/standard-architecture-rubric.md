# Standard Architecture Submission Rubric

**Course:** Enterprise Architecture Leadership Masterclass  
**Applies to:** Weekly architecture artifacts, labs (architecture portion), and capstone document  
**Scale:** 1–4 per criterion  
**Default use:** Score each criterion, multiply by weight, sum for submission score

---

## Criterion weights

| Criterion | Weight |
| --------- | -----: |
| Business alignment | 20% |
| Architecture quality | 20% |
| Trade-off analysis | 20% |
| Security and resilience | 15% |
| Feasibility and roadmap | 15% |
| Communication quality | 10% |

**Submission score** = Σ (criterion_score / 4 × weight × 100)

Example: all 3s → 75%.

---

## 1. Business alignment (20%)

| Score | Label | Description |
| ----- | ----- | ----------- |
| 4 | Excellent | Explicitly ties recommendations to NorthStar strategic objectives, outcomes, and KPIs. Stakeholders and value impact are clear. No technology-for-its-own-sake proposals. |
| 3 | Proficient | Links to business goals are present and mostly clear. Minor gaps in stakeholder or KPI connection. |
| 2 | Developing | Mentions business context but recommendations feel technology-led. Weak outcome traceability. |
| 1 | Incomplete | Little or no connection to NorthStar strategy or business outcomes. |

---

## 2. Architecture quality (20%)

| Score | Label | Description |
| ----- | ----- | ----------- |
| 4 | Excellent | Coherent structure across domains; clear boundaries, ownership, and interfaces. Diagrams and models are accurate and usable by practitioners. |
| 3 | Proficient | Sound architecture with minor inconsistencies or missing interface detail. |
| 2 | Developing | Partial model; significant gaps in structure, ownership, or interfaces. |
| 1 | Incomplete | Unusable as an architecture artifact; fragmented or incorrect. |

---

## 3. Trade-off analysis (20%)

| Score | Label | Description |
| ----- | ----- | ----------- |
| 4 | Excellent | Explicit alternatives with consequences across cost, risk, speed, complexity, and autonomy. Decision rationale is defensible in an ARB. |
| 3 | Proficient | Alternatives considered; consequences mostly clear. Some dimensions thin. |
| 2 | Developing | Single path asserted as “best practice” with little comparison. |
| 1 | Incomplete | No meaningful trade-off analysis. |

---

## 4. Security and resilience (15%)

| Score | Label | Description |
| ----- | ----- | ----------- |
| 4 | Excellent | Security, identity, data protection, and resilience are designed in—not bolted on. Risks and controls are specific and proportionate. |
| 3 | Proficient | Material security/resilience considerations present; minor gaps. |
| 2 | Developing | Generic security statements; weak control mapping or resilience targets. |
| 1 | Incomplete | Security/resilience largely ignored. |

*For early modules (1–2), grade proportionally to what is reasonably expected; still penalize unsafe or naïve assumptions.*

---

## 5. Feasibility and roadmap (15%)

| Score | Label | Description |
| ----- | ----- | ----------- |
| 4 | Excellent | Phased, dependency-aware, and realistic given coexistence and constraints. Value and risk reduction sequenced thoughtfully. |
| 3 | Proficient | Credible plan with minor sequencing or dependency gaps. |
| 2 | Developing | Big-bang or unrealistic; weak dependency handling. |
| 1 | Incomplete | No credible path from current to proposed state. |

---

## 6. Communication quality (10%)

| Score | Label | Description |
| ----- | ----- | ----------- |
| 4 | Excellent | Executive-ready clarity; appropriate audience language; clean structure; diagrams support the narrative. |
| 3 | Proficient | Clear and professional with minor editing needs. |
| 2 | Developing | Hard to follow; mixed audiences; cluttered visuals. |
| 1 | Incomplete | Unclear, incomplete, or unprofessional presentation. |

## Capstone additions

Capstone grading uses this rubric **plus** a completeness checklist for the 24 required artifacts (see `capstone/rubric/` when generated). Missing required artifacts cap the maximum score per cohort policy (default: incomplete checklist → maximum 69% on document portion until remediated).

## Presentation rubric (final presentation 15% of course)

| Criterion | Weight | Focus |
| --------- | -----: | ----- |
| Narrative and storyline | 25% | Problem → current → target → ask |
| Decision clarity | 25% | Explicit decisions requested |
| Trade-off defense | 20% | Handles challenge questions |
| Visual hierarchy | 15% | ≤15 slides, scannable |
| Executive language | 15% | Business outcomes over jargon |

Use 1–4 scale with the same Excellent / Proficient / Developing / Incomplete labels.
