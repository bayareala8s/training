# Assignment — Module 04: Target-State Architecture and Transformation Roadmaps

**Due:** Before the start of Module 05 live session (unless cohort calendar states otherwise)  
**Weight:** Contributes to Weekly labs / Architecture artifacts per assessment model  
**Rubric:** Standard architecture rubric + Module 04 emphasis  
**Case study:** NorthStar Financial Services (fictional)

---

## Purpose

Produce an executive-ready target-state and transformation roadmap package for NorthStar that demonstrates phased value, coexistence management, and defensible modernization dispositions.

## Learning objectives assessed

1. LO-4.1 — Define target-state architecture aligned to capabilities, principles, and constraints  
2. LO-4.2 — Justify modernization dispositions (including retain/replace/consolidate/retire)  
3. LO-4.3 — Design three transition architectures with exit criteria  
4. LO-4.4 — Build a dependency-aware 24-month roadmap with value, risks, and executive narrative  

## Instructions

1. Complete Lab 04 tasks using templates 24, 23, and 09 (or equivalent structure).  
2. Ensure dispositions cover at least eight apps/groups and include retain, replace, consolidate, and retire (not replace-only).  
3. Define Transition A/B/C with observable exit criteria and temporary interface end dates.  
4. Produce a 24-month roadmap with dependencies, value per phase, risk reduced per phase, value-versus-risk scores, risk register, and ≤1-page executive summary.  
5. Document assumptions and at least one explicit trade-off table or ADR-style decision.  

## Required deliverables

| # | Artifact | Format |
| - | -------- | ------ |
| 1 | Target-state architecture | Markdown (template 24) |
| 2 | Transition-state plan (A/B/C) | Markdown (template 23) |
| 3 | 24-month roadmap + value-vs-risk + risks + exec summary | Markdown (template 09) |

## Constraints

- Use NorthStar context and constraints  
- Explicitly document assumptions  
- Include at least one meaningful trade-off table or ADR-style decision  
- Address identity/audit/reconciliation in coexistence (proportionate depth)  
- No big-bang rewrite of StarCore as the only plan  
- No placeholder text
