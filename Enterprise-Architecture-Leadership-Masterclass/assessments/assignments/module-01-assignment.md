# Assignment — Module 01: The Enterprise Architect’s Role

**Due:** Before the start of Module 02 live session (unless cohort calendar states otherwise)  
**Weight:** Contributes to Weekly labs / Architecture artifacts per assessment model  
**Rubric:** Standard architecture rubric (see Module 01 emphasis notes)  
**Case study:** NorthStar Financial Services (fictional)

---

## Purpose

Produce a CIO-ready **Architecture Operating Model Pack** for NorthStar and a short narrative showing how you will lead the function **without relying solely on hierarchical authority**.

## Learning objectives assessed

1. M01-LO2 — Design operating model, decision rights, RACI, engagement  
2. M01-LO3 — Write 8–10 principles with exceptions and signals  
3. M01-LO4 — Influence without authority (90-day narrative)  
4. M01-LO1 — Reflected in mission and role clarity  

## Instructions

1. Complete Lab 01 deliverables (or refine your in-class drafts) using student instructions and templates.  
2. Ensure trade-offs are explicit: structural option chosen, options rejected, risks accepted.  
3. Add a **one-page (≤400 words) Influence & 90-Day Plan**: influence sources you will use, first wins, escalation thresholds, and how you will partner with BU architects.  
4. Include a title block with fiction notice.  
5. Self-check against the lab submission checklist before upload.

## Constraints

- Use NorthStar context and constraints  
- Explicitly document assumptions  
- Include at least one meaningful trade-off table (structural options and/or ARB scope)  
- Address security/resilience proportionately (RACI and/or principles)—do not ignore obvious late-engagement risk  
- Do not submit instructor reference solutions or answer keys
