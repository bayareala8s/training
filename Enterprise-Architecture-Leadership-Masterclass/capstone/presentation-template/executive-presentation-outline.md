# Executive Presentation Outline — Exactly 15 Slides

**Course:** Enterprise Architecture Leadership Masterclass  
**Format:** 15 minutes + 10 minutes Q&A  
**Case study:** NorthStar Financial Services (fictional)  
**Capstone artifact:** #24

Student copy: `student/templates/25-executive-presentation-outline.md`

Do not exceed 15 slides. Put detail in appendix docs, not the deck.

---

| Slide | Title | On-slide content (minimal) | Speaker intent |
| ----: | ----- | -------------------------- | -------------- |
| 1 | Title | Program name, your name, date, fiction notice | Set fiction + role |
| 2 | Stakes and outcomes | 4–5 outcomes / KPIs | Tie to strategy |
| 3 | Current-state diagnosis | 3–5 structural problems | Create urgency |
| 4 | Top risks / debt themes | Concentration, resilience, identity, sprawl | Risk clarity |
| 5 | Target-state vision | One diagram; name platforms/domains | Destination |
| 6 | Platform and cloud choices | Landing zone; what you reject | Leverage |
| 7 | Integration and data | Backbone; SoR / golden record | Reduce fragmentation |
| 8 | Security and resilience | Identity/PAM; RTO/RPO classes | Trust |
| 9 | AI (governed) | Use cases + HITL + audit | Value with control |
| 10 | 24-month roadmap waves | Wave outcomes, not task lists | Sequencing |
| 11 | Value versus investment | Phased value; stoppable spend | Defend choices |
| 12 | Governance model | Standards, guardrails, ARB, exceptions | Operating model |
| 13 | Material trade-offs | Two alternatives you did **not** choose | Trade-off defense |
| 14 | Decisions requested | Numbered approve / conditions | Close the ask |
| 15 | Risks, mitigations, close | Residual risks; owners; Q&A | Finish clean |

---

## Timing cue card

| Minutes | Focus |
| ------: | ----- |

| 2–5 | Diagnosis + risks |
| 5–10 | Target + platforms + security/AI |
| 10–13 | Roadmap + value + governance |
