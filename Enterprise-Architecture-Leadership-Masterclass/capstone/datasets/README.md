| Resource | Path |

The inventory contains **40+** fictional applications with ownership, hosting, cost, criticality, health, security risk, integrations, classification, and recommended disposition fields.

### Capstone usage

- Support artifacts **6–9** (portfolio assessment, current-state, integration landscape, debt register)
- Inform roadmap (artifact **20**), cost/risk summary (**21**), and ADR set (**22**)

### If the CSV is missing in a partial checkout

1. Use your Module 03 lab inventory export if you already created one.
2. Otherwise reconstruct a minimal 40-row inventory using the CSV header in the file and document assumptions in your current-state assessment.
3. Do **not** invent real company systems or regulated filings.

No additional proprietary datasets are required for the capstone.
