**Policy:** Missing required artifacts without instructor-approved remediation plan → **maximum 69%** on the document portion until remediated. If more than 3 required artifacts are Missing, apply the same cap until remediated.

| Completeness | Effect |
| ------------ | ------ |
| 24/24 | No cap from completeness |
| 22–23/24 with remediation plan | Instructor discretion; typically no hard cap if plan dated |
| ≤21/24 or silent gaps | Cap at 69% until fixed |

### ADR consistency check

The five ADRs (artifact 22) must not contradict the executive memo or presentation asks. Material contradictions reduce Trade-off analysis and Architecture quality scores.

## B. Presentation scoring (15% of course)

| Criterion | Weight | Focus |
| --------- | -----: | ----- |
| Narrative and storyline | 25% | Problem → current → target → ask |
| Decision clarity | 25% | Explicit decisions requested |
| Trade-off defense | 20% | Handles challenge questions |
| Visual hierarchy | 15% | ≤15 slides, scannable |
| Executive language | 15% | Business outcomes over jargon |

Scale 1–4 (Excellent / Proficient / Developing / Incomplete) per criterion.

**Hard constraints:** >15 slides or failure to present → Visual hierarchy max 2 if slide count exceeded; overall incomplete if no presentation.

## D. Panel question bank (sample)

1. What will you stop doing to fund this roadmap?
2. Why not multi-cloud as the default?
3. Where does autonomy remain for business units?
4. What is the first measurable value in 90 days?
