# AWS Draw.io starter — Landing Zone frame

Open in diagrams.net → **Arrange → Insert → Advanced → CSV** or manually enable shape library **AWS / AWS19**.

Recommended groups (progressive reveal):

1. `g1_org` — AWS Organizations / OUs  
2. `g2_identity` — IAM / Identity Center  
3. `g3_logging` — CloudTrail → S3  
4. `g4_network` — VPC baseline  
5. `g5_workloads` — App accounts  
6. `g6_guardrails` — SCPs / Config / Budgets  

Color tokens: see [`../standards/VISUAL_STYLE_GUIDE.md`](../standards/VISUAL_STYLE_GUIDE.md).

Always use official product icons for: Organizations, IAM, CloudTrail, S3, Config, Budgets, VPC.
