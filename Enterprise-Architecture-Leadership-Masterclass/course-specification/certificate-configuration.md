## Eligibility rules

Issue the certificate only when **all** of the following are met:

| Rule | Threshold |
| ---- | --------- |
| Live session attendance | ≥ 70% |
| Required assignments completed | ≥ 80% |
| Overall course score | ≥ 70% |
| Capstone document submitted | Yes (24 artifacts or instructor-approved remediation) |
| Capstone presentation delivered | Yes (panel: 15 min + 10 min Q&A) |

Quizzes are formative by default and do not gate certificate issuance unless a cohort explicitly weights them and communicates that before Week 1.
