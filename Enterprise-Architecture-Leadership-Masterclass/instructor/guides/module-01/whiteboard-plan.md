# Whiteboard Plan — Module 01: The Enterprise Architect’s Role

**Format:** Physical whiteboard, Miro, or tablet; dark navy digital background with white/gold markers preferred for BayLearn brand  
**Case study:** NorthStar Financial Services (fictional)

---

## Board 1 — EA decision stack (Lesson 1.1) | ~5 min

Draw top-down:

```text
Strategy outcomes
Capabilities & value streams
Investment themes & constraints
Principles & decision rights
Platforms / patterns / guardrails
Solution choices
```

**Say while drawing:** “When someone asks ‘buy Product X?’, climb up—don’t start at features.”

**Leave up** for the rest of class (reference during lab).

---

## Board 2 — Operating model options (Lesson 1.2) | ~8 min

Three columns: **Central | Federated | Hybrid**

Under each: 2 pros, 2 cons, “fits when…”

Star **Hybrid** for NorthStar Year 1; write underneath: *“Fit ≠ universal best practice.”*

Add sticky: “BU architects already exist → coalition.”

---

## Board 3 — Decision classes + engagement funnel (Lesson 1.2) | ~7 min

### Table

| Class | Accountable (example) |
| ----- | --------------------- |
| Local within guardrails | SA / EM |
| Domain pattern / target | Domain architect |
| Enterprise principles | Lead EA (CIO approve) |
| Golden path change | Platform (+ EA/Sec consult) |
| Material exception | ARB / ExCo tech |

### Funnel

`Request → Triage → Consult | Collaborate | Govern`

**Exercise:** Place “second API gateway” on the board with a magnet/sticky.

---

## Board 4 — Principle anatomy (Lesson 1.3) | ~5 min

Boxes: Name → Statement → Rationale → Implications → Exceptions → Signals

Cross out a bad example: “Be cloud-native.”  
Write a good stub: “Prefer platform golden paths.”

Add exception loop: Request → Risk → Decision → Expiry.

---

## Board 5 — Influence sources (Lesson 1.4) | ~4 min

Six bubbles around “Lead EA”: Expertise, Network, Process, Sponsorship, Delivery credibility, Evidence.

Arrow sequence: `Listen → Frame → Principles → One win → Risk reporting → Expand rights`
