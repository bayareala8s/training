## Launch script (2 minutes)

> You are NorthStar’s Lead EA. Architects already sit in BUs; governance is inconsistent. In 40 minutes, produce a first-cut operating-model pack: mission, diagram, RACI, 8–10 principles, decision rights, engagement model, and a risk register for the architecture function. Pair discussion is fine; submissions are individual. I will do a mid-lab check. Incomplete polish becomes homework—we will still debrief on time.

Point to: `labs/lab-01-architecture-operating-model/student-instructions.md`

---

## Suggested student sequencing (coach this order)

| Minutes | Focus |
| ------: | ----- |
| 0–5 | Mission + operating-model option choice (hybrid default OK if justified) |
| 5–12 | Decision classes + RACI skeleton |
| 12–22 | Principles (aim for 8; quality over 12 slogans) |
| 22–30 | Engagement model + diagram |
| 30–40 | Risk register + self-check against submission checklist |

If stuck, tell them: **decision classes before pretty diagrams.**

---

## Mid-lab check (~minute 20 of lab)

Ask the room (2 minutes):

> What decision is hardest right now—and what evidence would make it easier?

Common answers: ARB scope, who is Accountable for platforms, principle count. Normalize struggle.

Circulate; spend more time with students writing technology shopping lists or dual Accountables.

---

## Facilitation dos and don’ts

| Do | Don’t |
| -- | ----- |
| Challenge trade-offs | Dictate hybrid as dogma |
| Push plain-language mission | Rewrite their artifacts for them |
| Require single Accountable | Project the reference solution |
| Protect debrief time | Extend lab into debrief window |
| Note strong examples for review | Shame incomplete labs |

---

## Selecting debrief volunteers

Prefer:

1. One hybrid model with clear rejected alternatives  
2. One student who chose centralized or federated *with* a strong defense  
3. Optional: strongest principle set

Ask ARB-style questions from module `debrief-questions.md`.

---

## Incomplete lab policy

State explicitly:

- Minimum for in-class participation credit (cohort policy): mission + decision classes + ≥6 principles drafted  
- Full credit requires all deliverables per checklist by assignment due date  
- Stretch objectives are optional and do not replace core artifacts
