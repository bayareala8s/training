# Common Misconceptions — Module 09

| Misconception | Correction |
| ------------- | ---------- |
| “Governance slows delivery” | Ungoverned divergence slows the enterprise via rework, dual ops, and audit failure |
| “ARB approves projects” | ARB disposes architecture risk; funding remains an executive/product decision |
| “Standards kill innovation” | Golden paths accelerate common cases; exceptions handle true novelty |
| “Licenses already signed = must approve” | Commercial commitments inform options; they do not dictate architecture |
| “One ADR is enough” | Independent irreversible choices need independent records |
| “Security can only say no” | Security must propose compensating controls and safer paths |
