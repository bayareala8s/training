# Instructor Guide — Module 03: Current-State Architecture Assessment

**Audience:** BayLearn instructors  
**Classification:** Instructor-only when combined with reference solutions / answer keys

---

## 1. Module purpose

Teach decision-driven current-state assessment using discovery design, TIME, dependency concentration, and executive risk/debt narratives—anchored in the fictional NorthStar application inventory.

## 2. Learning objectives

1. Design scoped discovery for decision-quality insight.
2. Apply TIME with transparent rationale; challenge seed dispositions.
3. Map dependency hubs and duplicate clusters.
4. Rank risks/debt with business impact.

## 3. Prerequisites

Module 02 capability draft; CSV openable; TIME and debt templates skimmed.

## 4. Estimated timing (120 minutes)

| Segment | Minutes |
| ------- | ------: |
| Scenario + discovery (3.1) | 15 |
| TIME concept (3.2) | 20 |
| Instructor demo on CSV sample | 15 |
| Guided lab | 40 |
| Architecture review | 15 |
| Assignment briefing | 10 |
| Buffer | 5 |

## 5. Opening business scenario

ExCo wants risk visibility and cost levers now. A perfect CMDB will not arrive in time. Students must scope, score, and narrate.

## 6. Lesson flow

1. Discovery as design (timebox + confidence).
2. TIME clinic on 3 live CSV rows (including one overturn).
3. Demo hubs: ESB, dual gateways, dual masters.
4. Lab with scoped TIME + top risks.
5. Review + assignment.

## 7. Questions to ask

1. What decision does this assessment unlock?
2. Why might Tolerate be correct for SAP/Workday?
3. What breaks if we Eliminate Gateway A next month?
4. Where is the business interest on this debt?

## 8. Whiteboard sequence

See `whiteboard-plan.md`.

## 9. Demonstration steps

1. Filter CSV: Mission Critical + Integration capability apps.
2. Score 2–3 apps aloud; overturn one seed disposition with rationale.
3. Sketch ESB hub + dual customer masters; link to Module 02 themes.

## 10. Break points

After concept (~35); mid-lab (~75).

## 11. Lab facilitation

See `lab-facilitation-guide.md`. Protect final 25 minutes.

## 12. Common student issues

| Issue | Response |
| ----- | -------- |
| Copies all CSV dispositions | Require ≥3 challenges with rationale |
| Scores all 45 equally deep | Force a scope slice |
| Tech-only risks | Demand business impact sentence |
| No Module 02 link | Ask which capability theme is evidenced |

## 13. Debrief questions

Use module `debrief-questions.md`.

## 14. Assignment briefing

Executive current-state briefing: TIME summary, hubs, top-10 risks, implications for roadmap. Rubric emphasizes trade-offs, alignment, feasibility.

## 15. Suggested homework

Finish lab; formative quiz; skim Module 04 target-state teaser.
