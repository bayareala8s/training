# Common Misconceptions — Module 05

| Misconception | Correction |
| ------------- | ---------- |
| “Landing zone = Control Tower checkbox” | Landing zone is an operating model + guardrails, not a single product |
| “Multi-cloud reduces risk automatically” | It can increase operational risk if platforms duplicate |
| “FinOps is reporting” | FinOps is allocation, accountability, and action loops |
| “Platform teams must build everything” | Prefer buy/reuse for commodity controls |
| “Public health API is fine in prod” | Lab convenience ≠ production exposure pattern |
