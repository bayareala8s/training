# Discussion Questions — Module 06

Use during concept blocks, mid-lab, or architecture review. Prefer trade-off answers over slogans.

1. Should analytics teams be allowed to publish “account corrections” events? Who owns the authoritative correction path?
2. What is the consumer contract for `PaymentSubmitted`—ordering, exactly-once, schema versioning, and replay?
3. How do you prevent partner-file storms from starving payment workers without building a second enterprise?
4. Where do schema registries fit in NorthStar’s year-one roadmap versus “JSON in a wiki”?
5. When is a shared database anti-pattern worth escalating to ExCo versus quietly tolerated for 90 days?
6. How should EA respond when a LOB insists on an ESB “because we already have one” for every new interface?
7. What evidence would convince you to approve AWS Transfer Family for production partners despite idle-endpoint cost?
8. How does this week’s reference architecture feed Module 07 security and resilience conversations (IAM, DLQ, blast radius)?
