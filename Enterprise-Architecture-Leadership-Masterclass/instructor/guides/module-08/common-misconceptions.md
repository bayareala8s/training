# Common Misconceptions — Module 08

| Misconception | Reality | Teaching move |
| ------------- | ------- | ------------- |
| More pilots = AI strategy | Strategy is a governed portfolio of use cases with KPIs | Scorecard before models |
| Free text is fine for ops decisions | Structured JSON + validation enables control | Schema fail demo |
| HITL means a human reads everything | HITL is triggered by risk/confidence rules | Trigger sticky board |
| Model output is the business decision | Deterministic rules separate propose vs decide | Pipeline board |
| Logging full prompts with PII is OK | Safe logging and redaction are mandatory | Synthetic-only reminder |
| Mock mode is “cheating” | Mock teaches governance when Bedrock is gated | Grade architecture/eval equally |
| Eval can wait until production | Labeled set defines quality before scale | Score 5 rows live |
| Tokens are not architecture | Cost/latency/limits are NFRs | Cost note required |
| Autonomous actions are the goal | Advise-first is default for financial ops | Ban auto-execute in lab |
| One chatbot serves all LOBs | Shared platform patterns ≠ one undifferentiated bot | Portfolio language |
