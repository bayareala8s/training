## Facilitation cues by theme

### Target state

- Hammer non-goals.  
- Keep diagrams pattern-level.  
- Fiction notice on first NorthStar content slide.

### Strategies

- Ban “migrate” as a lone answer.  
- Use CRM and file-bridge examples for consolidate.  
- Honor retain as legitimate.

### Transitions

- Exit criteria must be measurable.  
- Call out dual-write reconciliation.  
- Temporary interface register mention.

### Roadmaps

- Separate roadmap from project plan.  
- Force dependency callout.  
- Value per phase in business language.

## Demo hygiene

- Use partial sample only.  
- Narrate trade-offs out loud.  
- Stop before full reference solution depth.

## Lab slide

- Show deliverable table once.  
- Point to templates 23/24/09.  
- Start timer visibly.

## Risks to avoid on slides

- Too much text  
- Vendor logos as “architecture”  
- Cartoon imagery  
- Implying NorthStar is real
