# Lab Facilitation Guide — Module 04

**Lab:** Create NorthStar’s Target-State Roadmap  
**Path:** `labs/lab-04-target-state-roadmap/`  
**In-session target:** Draft quality; polish as homework  
**Case study:** NorthStar Financial Services (fictional)

---

## Pre-lab setup (5 minutes before start)

- [ ] Student instructions link posted  
- [ ] Templates 23, 24, 09 available  
- [ ] Whiteboard Board 2–4 still visible or photographed  
- [ ] Remind: individual submission even if paired discussion  
- [ ] State success bar: dispositions + 3 transitions + roadmap skeleton by end of lab block  

## Kickoff script (2 minutes)

> You are Lead EA. Produce artifacts an exec committee can challenge. Start with capabilities and principles—do not jump to a Gantt chart. I will ask about exit criteria at the mid-check.

## Suggested student sequencing (35–40 minutes)

| Minutes | Focus |
| ------: | ----- |
| 0–8 | Tasks 1–2: capabilities + principles |
| 8–16 | Tasks 3–4: target patterns + dispositions |
| 16–28 | Task 5: three transitions + exits |
| 28–38 | Tasks 6–7: roadmap skeleton + risks + exec bullets |
| 38–40 | Self-validate against checklist |

## Mid-lab check (~halfway)

Ask whole room:

1. Hardest disposition—and what evidence would help?  
2. Read one exit criterion aloud—is it observable?

Coach patterns:

- StarCore → retain + replatform  
- CRMs → consolidate with survivor  
- File platforms → consolidate/retire via API path for new volume first  

## Circulating prompts

| If you see… | Say… |
| ----------- | ---- |
| Only replaces | “Where do you retain—and why is that courageous?” |
| No dual-run | “Show me the Month 12 operating cost of coexistence.” |
| Vague exits | “What metric turns green?” |
| Month-1 everything | “What must finish before onboarding strangler starts?” |
| No identity | “Who authenticates dual-write operators in Transition B?” |

## Architecture review (post-lab, 10 minutes)

Volunteer 1–2 drafts. ARB-style questions only:

- Alignment to strategy?  
- Alternatives considered?  
- Feasibility given coexistence?  
- Biggest risk?

Do not copy-edit formatting live.

## Incomplete labs

Normalize: “Skeleton today, polish before next session.” Collect blockers on a parking lot for office hours.

## Accessibility / inclusion

- Allow table-only submissions (diagrams optional if structure clear)  
- Provide quiet work option; pairing optional  
- Avoid calling out BU “losers” with student names—keep fiction in NorthStar personas  

## After class

- Post debrief questions  
- Remind assignment due before Module 05  
- Do not share reference solution
