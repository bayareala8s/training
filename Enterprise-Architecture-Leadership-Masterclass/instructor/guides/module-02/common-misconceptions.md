# Common Misconceptions — Module 02

| Misconception | Reality | Teaching move |
| ------------- | ------- | ------------- |
| Capabilities = applications | Capabilities outlive systems | Rename drill |
| Capability maps replace roadmaps | Maps inform roadmaps; they are not schedules | Point to Module 04 |
| Heatmaps are objective truth | They are decision aids with assumptions | Require confidence ratings |
| EA owns business capabilities | EA facilitates; business owns outcomes | RACI reminder |
| More detail = better architecture | Premature L3 creates false precision | Timebox depth |
| Value streams are IT process maps | Value streams are outcome flows; IT enables | Stage/outcome framing |
| All red means “rebuild everything” | Prioritize; coexistence is a constraint | Force top-3 investments only |
