# Lab Facilitation Guide — Module 02

**Lab:** Build NorthStar’s Business Capability Map  
**Student path:** `labs/lab-02-capability-mapping/`

---

## Setup (before class)

- Confirm templates 06, 21, 22 are visible in student package
- Prep reference solution privately (do not share)
- Create a shared “Parking lot: applications” channel/board

## Launch script (2 min)

> You are Lead EA. Produce a map an ExCo member could navigate. Systems are out of scope except as evidence notes. Forty minutes. Individual submission even if you pair for ideation.

## Progress checkpoints

| Time | Check |
| ---- | ----- |
| +10 min | L1 list exists (8+); at least one Core/Commodity labeled |
| +20 min | Five L2 expansions started; owners draft |
| +30 min | Onboarding stages sketched; two frictions named |
| +40 min | Heatmap legend + 5 scored capabilities minimum |

## Stuck-student prompts

- “Name the business outcome if this capability disappeared tomorrow.”
- “Would this name survive a reorg?”
- “What evidence would an auditor accept for that maturity score?”

## Review selection

Prefer one structurally strong map and one politically interesting ownership debate—not the prettiest formatting.
