# Common Misconceptions — Module 07

| Misconception | Reality to teach |
| ------------- | ---------------- |
| Private network = Zero Trust | Identity, least privilege, and continuous detection still required |
| Encryption fixes disclosure | Without IAM scoping, authorized-but-overbroad access remains |
| RTO/RPO are IT preferences | They are business impact targets with cost consequences |
| Replication equals tested DR | Untested replication is hope; drills produce evidence |
| Compliance is a tool checkbox | Compliance needs control objectives + evidence freshness + owners |
| Lab Admin rights are fine forever | Lab may use elevated deploy rights; architecture must still model least privilege |
