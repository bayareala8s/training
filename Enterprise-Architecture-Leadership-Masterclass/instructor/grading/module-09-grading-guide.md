# Grading Guide — Module 09

**Assessments:** Lab 09 package + Assignment 09 (often the same polished artifacts) + formative quiz + ARB participation

## Standard rubric emphasis this week

| Criterion | Emphasis |
| --------- | -------- |
| Business alignment | High — merchant outcomes vs. enterprise tax |
| Architecture quality | Medium — clear decision structure |
| Trade-off analysis | Very high — alternatives and precedent |
| Security and resilience | Very high — access, keys, logging, DR |
| Feasibility and roadmap | High — alternate path with sequencing |
| Communication quality | Very high — memo clarity |

## Participation (Architecture review participation 10%)

Score 1–4 on: preparation, role fidelity, constructive challenge, decision quality.  
Average × 10% course weight contribution as defined by cohort gradebook.

## Quick fail conditions (cap at Developing / score 2 max on related criteria)

- No explicit disposition for each of four requests  
- Approve standing contractor admin without compensating controls  
- Memo without a clear ask  
- No alternatives in ADRs

## Feedback stems

- “Split cloud and data decisions—your ADR currently conflates them.”  
- “Name an owner and expiry for each condition.”  
- “Your alternate path needs a critical-path date, not only principles.”
