# Grading Guide — Module 10 / Capstone

## Course weights

| Component | Weight |
| --------- | -----: |
| Capstone document | 20% |
| Final presentation | 15% |
| Module 10 assignment elements (leadership plan) | within artifacts / as cohort configured |

## Document scoring

1. Score standard architecture rubric (1–4 × weights).  
2. Apply completeness checklist: if required artifacts missing without approved remediation, **cap document portion at 69%** until remediated (default policy).  
3. Check ADR consistency with presentation asks.

## Presentation scoring

Use presentation rubric in `capstone/rubric/capstone-rubric.md` (narrative, decision clarity, trade-off defense, visual hierarchy, executive language).

## Panel protocol

- Independent scores first  
- Moderate outliers >1 point apart  
- Written feedback: one strength, two improvements
