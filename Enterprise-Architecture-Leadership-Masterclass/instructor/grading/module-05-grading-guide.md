# Grading Guide — Module 05

Use `assessments/rubrics/standard-architecture-rubric.md` + `assessments/rubrics/module-05-rubric.md`.

## Quick score anchors

| Level | Evidence |
| ----- | -------- |
| Excellent | Clear posture, owned LZ diagram, weighted build-vs-buy, FinOps policy actionable, lab validated + cleaned |
| Good | Complete artifacts, minor gaps in ownership or trade-offs |
| Developing | Generic cloud advice; weak ADR; lab incomplete without explanation |
| Insufficient | No trade-offs; no cleanup; copied slogans |

## Lab evidence minimum

Health JSON + destroy confirmation + tags mentioned.
