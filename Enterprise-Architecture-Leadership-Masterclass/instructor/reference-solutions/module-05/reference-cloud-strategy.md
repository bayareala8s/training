# Reference — NorthStar Cloud Strategy (Fictional)

## Executive summary

NorthStar adopts **cloud-first for new digital products**, **hybrid coexistence** for acquired cores over 24 months, and a **single primary cloud provider** with documented exit criteria. Shared landing-zone standards and FinOps guardrails precede accelerated migration waves.

## Posture

| Topic | Position |
| ----- | -------- |
| Hybrid | Yes—coexistence required |
| Multi-cloud active-active | No for year one |
| Default provider | One primary hyperscaler |
| Placement | Classification, latency, skills, TCO, evidence needs |

## Principles (sample)

1. Platform baselines before migration velocity
2. Identity and audit are non-negotiable shared services
3. Tags and budgets are release gates for platform use
4. Prefer buy/reuse for commodity controls
5. Sandboxes expire; production has owners

## Platform capabilities (priority)

Identity, central logging, FinOps tagging/budgets, secrets, CI baseline, observability baseline.
