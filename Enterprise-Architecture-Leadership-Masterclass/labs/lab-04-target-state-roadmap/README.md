# Lab 04 — Create NorthStar’s Target-State Roadmap

**Module:** 04 — Target-State Architecture and Transformation Roadmaps  
**Estimated duration:** 40 minutes guided + homework completion  
**Estimated cost:** N/A (non-AWS)  
**Case study:** NorthStar Financial Services (fictional)  
**Student role:** Lead Enterprise Architect

---

## Overview

You will produce a complete target-state and transformation roadmap package for NorthStar: strategic capabilities, target principles, target application architecture, disposition decisions, three transition states, a 24-month roadmap with dependencies and value per phase, risks, and an executive summary.
