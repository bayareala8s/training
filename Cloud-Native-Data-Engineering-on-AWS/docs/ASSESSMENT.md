# Assessment Structure

## Grading Breakdown

| Assessment | Weight | Description |
|------------|--------|-------------|
| Weekly Labs | 30% | Hands-on exercises completed each week |
| Assignments | 20% | Written and practical assignments |
| Architecture Reviews | 10% | Design reviews and peer feedback |
| Data Platform Project | 10% | Mid-course platform milestone |
| Capstone Project | 30% | Final enterprise capstone deliverable |

---

## Weekly Labs (30%)

Each module includes hands-on labs. Labs are evaluated on:

- Correct implementation of AWS services
- Code quality and documentation
- Pipeline reliability and error handling
- Adherence to best practices

---

## Assignments (20%)

Assignments may include:

- Architecture design documents
- Data modeling exercises
- SQL and Python scripting tasks
- Cost analysis reports
- Security and governance reviews

---

## Architecture Reviews (10%)

Students present and defend data platform designs covering:

- Ingestion patterns
- Storage and partitioning strategy
- ETL workflow design
- Security and governance controls
- Monitoring and operational readiness

---

## Data Platform Project (10%)

Mid-course milestone demonstrating an integrated data platform with:

- S3 data lake (Raw/Cleaned/Curated zones)
- At least one ingestion pipeline
- Glue ETL job(s)
- Data catalog entries
- Basic monitoring

---

## Capstone Project (30%)

Final project selected from one of four enterprise scenarios. See [capstone/README.md](../capstone/README.md).

### Required Deliverables

- Architecture diagrams
- ETL workflows
- Glue jobs
- Data catalogs
- Monitoring dashboards
- Governance controls
- Cost analysis
- Final presentation (15–20 minutes)

### Evaluation Criteria

| Criterion | Weight |
|-----------|--------|
| Architecture & Design | 25% |
| Implementation Quality | 25% |
| Data Quality & Governance | 20% |
| Monitoring & Operations | 15% |
| Documentation & Presentation | 15% |

---

## Passing Requirements

- Minimum overall score: **70%**
- Capstone project must be submitted and presented
- All weekly labs must be attempted (minimum 8 of 10 submitted)
