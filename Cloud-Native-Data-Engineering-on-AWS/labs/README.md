## Lab Structure

```text
modules/module-XX/labs/lab-X.X-title/
├── README.md           # Instructions, troubleshooting, deliverables
├── diagram.md          # Architecture diagrams (Mermaid)
├── src/ or scripts/    # Code (Python, SQL, JSON, ASL)
├── sample-data/        # Synthetic test data (where applicable)
└── LAB-REPORT.md       # Student submission (you create)
```

## Prerequisites for All Labs

- [Environment setup](../setup/SETUP.md) complete
- Shared lab environment running: `./scripts/lab-cycle.sh start` then `source ./scripts/lab-env.sh`
- Python virtual environment with `requirements.txt` installed

Stop when finished: `./scripts/lab-cycle.sh stop --yes` (zero ongoing AWS cost)

## Lab Submission

Each lab requires a `LAB-REPORT.md` with screenshots and verification output. See [Student Handbook](../docs/STUDENT-HANDBOOK.md).
