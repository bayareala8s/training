# Assessment Structure

| Assessment | Weight | Notes |
|------------|--------|-------|
| Weekly Labs | 30% | Modules 1–9 hands-on deliverables |
| Assignments | 20% | Written and design exercises |
| Architecture Reviews | 10% | Peer/instructor review sessions |
| CI/CD Project | 10% | Module 9 pipeline deliverable |
| Capstone Project | 30% | Module 10 full platform |

## Weekly Lab Deliverables (Summary)

| Module | Deliverable |
|--------|-------------|
| 1 | Service decomposition document, context mapping diagram |
| 2 | OpenAPI documentation, API contracts |
| 3 | Dockerfiles, container registry setup |
| 4 | Running microservices platform on ECS |
| 5 | Event-driven workflow |
| 6 | Distributed data model |
| 7 | Secure authentication platform |
| 8 | Observability platform (dashboards, tracing, alerts) |
| 9 | Production CI/CD pipeline |

## Capstone Requirements

Students must submit:

- Architecture diagrams
- Source code repositories
- CI/CD pipelines
- Observability dashboards
- Security review
- Cost analysis
- Final demo
