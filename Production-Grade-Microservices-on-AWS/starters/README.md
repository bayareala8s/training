# Service Starters (Multi-Track)

Students choose one implementation track for hands-on work. All tracks implement the same API contracts (OpenAPI) defined in Module 2.

| Track | Path | Framework |
|-------|------|-----------|
| Python | `python/` | FastAPI |
| Java | `java/` | Spring Boot |
| Node.js | `nodejs/` | NestJS |

## Planned Services

- `user-service/`
- `product-service/`
- `order-service/`
- `notification-service/`

Starters will be added per module release. Module 2 begins with User and Product services.
