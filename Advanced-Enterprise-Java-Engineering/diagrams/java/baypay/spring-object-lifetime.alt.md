Diagram: Harbor Market sends POST /api/v1/payments into one OS process running a Java 21 Spring Boot JVM. Tomcat worker threads share an ApplicationContext of singleton beans: PaymentController, a transactional PaymentApplicationService proxy, Spring Data repository proxies, Clock, PaymentAuthorizer, in-process posting and notify, and a Hikari pool. One POST allocates CreatePaymentRequest, Money, a Payment entity, and an EntityManager that close after commit. The payments row lives in H2 or Postgres outside the JVM. BayPay is fictional instruction.
