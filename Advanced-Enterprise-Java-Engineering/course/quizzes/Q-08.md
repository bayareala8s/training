3. **B.** Do not bounce Postgres/the cell first.
4. **B.** HTTP exhausted; waiters are not Hikari.
5. **B.** Allocation storm, stable old gen.
6. **B.** cgroup OOM ≠ heap OOME.
7. **B.** Method over lucky nouns.
8. **B.** Isolate the canary.
