<details>
<summary>Spoiler — answers</summary>

1. **B.** Heap ≠ RSS. Use NMT.
2. **B.** Domain immutability ≠ no allocation.
3. **B.** Do not `-Xcomp` in prod.
4. **B.** Young GC is normal.
5. **B.** Threads and cgroup first.
6. **B.** Never `-Xmx` = limit.
7. **B.** Metaspace is class metadata.
8. **B.** Retained vs garbage.

</details>
