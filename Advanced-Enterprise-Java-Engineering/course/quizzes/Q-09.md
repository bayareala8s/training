<summary>Spoiler — answers</summary>

1. **B.** Image ≠ running container.
2. **B.** JRE in runtime, JDK in build.
3. **B.** Secrets do not belong in layers.
4. **B.** Pin versions or digests.
5. **B.** Never `-Xmx` = limit.
6. **B.** Non-root UID.
7. **B.** Layer cache.
8. **B.** Do not ship ND-in-Docker as the target.
