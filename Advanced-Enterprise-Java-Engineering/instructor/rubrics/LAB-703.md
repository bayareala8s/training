# Rubric — LAB-703 Observe GC

Score each dimension 0–100, then apply the weight. A JFR GUI screenshot with no pasted unified-log lines is not a high Technical score. Instructor synthetic lines in `solutions/LAB-703` are not student evidence.

| Dimension | Weight | 100 | 60 | 20 |
|---|---|---|---|---|
| Technical accuracy | 25% | 3–5 **own** lines; young vs full/old (or honest young-only + next step); `before->after(capacity)` and pause parsed | Lines pasted; young/old mixed up once | Blog paste; JFR-only; no Pause reading |
| Diagnostic method | 20% | Two runs (G1 + Serial or smaller `-Xmx`); flags and file names recorded | One log, some annotation | Opened solution log as own |
| Production awareness | 15% | G1 as BayPay default; Serial/small heap is visibility, not prod-east advice; no Module 8 RCA | Mentions G1 | Recommends Serial for payment-service |
| Trade-off analysis | 15% | Cost of `gc*` to disk; retain (LAB-702) vs dying chunks; STW vs concurrent start | One honest trade-off | None |
| Security / reliability | 10% | Logs are local; no customer payloads; pause ≠ “heap corrupt” | Harmless | Treats Allocation Failure as a breach |
| Communication | 10% | Worksheet GC section readable | Lines without annotations | Empty |
| Efficiency | 5% | Text logs, `$0`, no GUI required | Extra unused JFR | Cloud APM as if required |

**Pass guideline:** weighted score ≥ 70, own unified-log lines, and at least one correct young-pause reading.
