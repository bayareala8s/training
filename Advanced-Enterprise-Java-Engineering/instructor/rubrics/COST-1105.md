# Rubric — COST-1105 Cost optimization

**Type:** COST (awsLab, paper + pricing)  
**Weights:** Technical accuracy 25% · Diagnostic method 20% · Production awareness 15% · Trade-off analysis 15% · Security / reliability 10% · Communication 10% · Efficiency 5%

Score each dimension 0–100, then apply the weight. Cost Explorer and `terraform apply` must not be required to pass.

| Dimension | Weight | 100 | 60 | 20 |
|---|---|---|---|---|
| Technical accuracy | 25% | Shown multiply; ALB 24h ≈ $0.54; Fargate ≈ $0.012/h; NAT 24h ≈ $1.08; EKS 24h ≈ $2.40; ECR 7d pennies | Most figures present; one window missing | No arithmetic; ALB treated as free when idle |
| Diagnostic method | 20% | Used BUILD-1101 resource list + teaching rate table before totaling | Totals without a rate source | Opened `solutions/` first |
| Production awareness | 15% | Destroy same day; idle ALB is the surprise; `desired_count = 0` does not stop ALB; Expiration ≠ delete | Mentions destroy vaguely | Left an ALB up, or added NAT/EKS “to see the bill” |
| Trade-off analysis | 15% | Fargate vs t3 for same-day vs 24/7; public+IGW vs NAT; shared ALB vs per-student | One honest trade-off | Always-on EC2 as the student default |
| Security / reliability | 10% | Public-IP trade-off named; no admin policy to read prices | Mentions public subnet | Opens 8080 to the world “to avoid NAT” |
| Communication | 10% | PF-aws-cost.md complete; destroy list names ALB, ECS, ECR | Incomplete table | Empty worksheet |
| Efficiency | 5% | Paper only; 60–90 minutes | Finished in session | Applied EKS/NAT/RDS as if required |

**Pass guideline:** weighted score ≥ 70, ALB hourly cost shown, NAT and EKS refused with a dollar figure, destroy list names ALB/ECS/ECR. Optional live pricing lookup is fine if sourced. Creating NAT or EKS for this lab caps Production awareness at 20 or below.
