# Rubric — AI-1503 Runbook recommendation

**Type:** AI  
**awsLab:** no (files only)  
**Weights:** Technical accuracy 25% · Diagnostic method 20% · Production awareness 15% · Trade-off analysis 15% · Security / reliability 10% · Communication 10% · Efficiency 5%

An auto-approved runbook, or one that still **disables TLS**, **bounces `dmgr-east`**, or **bounces Postgres**, must **not** max Production awareness or Security / reliability.

| Dimension | 5 | 3 | 1 |
|---|---|---|---|
| Technical accuracy | Four buckets; cert/edge **check** in investigation; restore HTTPS as stabilize; TLS-off / ND / Postgres **withdrawn**; schema-shaped | Checks named; one unsafe action left in | Ships the starter mutates |
| Diagnostic method | Listed the four unsafe starter moves before rewrite; excerpt quotes handshake + RUNNING + `:8080` 200 | Rewrote without listing starter breaks | Opened `solutions/AI-1503/` first |
| Production awareness | Every mutate `approvalRequired: true`; `humanApproval` pending or **named reject** of `BayOps-auto`; no TLS-off; no `dmgr-east`; no Postgres | Approval field present; one refusal missing | Auto-approve remains, or executes TLS-off / cell / DB |
| Trade-off analysis | Signed restore-HTTPS vs wait-for-issue; paper runbook vs Lambda auto-execute; why `approvalRequired` is const true | Mentions approval | Treats auto-execute as the design |
| Security / reliability | TLS stays on; no private key; leftover ND refused; Avery still on HTTPS | Mentions HTTPS | Disable TLS “just for an hour” |
| Communication | Names the refusals and who must sign; no proven RCA | Usable | “Approved — bounce everything” |
| Efficiency | 45–60 minutes; no live listener/ACM/Bedrock | Complete but slow | Incomplete or paid apply to “run the book” |

A runbook that restores HTTPS but leaves `humanApproval.status=approved` by `BayOps-auto` caps Production awareness at 1.

**Pass guideline:** weighted score ≥ 70, cert/edge check present, all remediations `approvalRequired: true`, human approval not auto, **no** TLS disable, **no** `dmgr-east` / PaymentCluster, **no** Postgres bounce.
