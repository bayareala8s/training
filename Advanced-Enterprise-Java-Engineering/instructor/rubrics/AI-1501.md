# Rubric — AI-1501 Incident summarization

**Type:** AI  
**awsLab:** no (files only)  
**Weights:** Technical accuracy 25% · Diagnostic method 20% · Production awareness 15% · Trade-off analysis 15% · Security / reliability 10% · Communication 10% · Efficiency 5%

A lucky “the database is down” (or “just a bad deploy”) with no quoted **rate**, no quoted **P99**, and no quoted **Hikari pending** must **not** max Diagnostic method (20%).

Do **not** require the Module 13 instructor RCA (cardinality / `customerId` tags / series explosion) to pass this lab.

| Dimension | 5 | 3 | 1 |
|---|---|---|---|
| Technical accuracy | Four buckets; quotes rate **~180→~22**, P99 **~118 ms→~4.8 s**, 5xx not the page; Hikari pending **0**; no `invented/db-down.txt`; `provenRootCause` null/absent | Buckets present; one symptom quote missing | Keeps “database is down” as proven RCA |
| Diagnostic method | Read excerpt before rewrite; circled mixed-starter violations; withdrew/weakened DB hypothesis from **quoted** pending=0 / omitted DB file | Rewrote without listing starter breaks | Opened `solutions/AI-1501/` first, or proven stamp with no quotes |
| Production awareness | No Postgres bounce; no `dmgr-east`; remediations `approvalRequired: true`; `humanApproval` pending or named — not `BayOps-auto` | Pending missing but no bounce | Auto-approve + bounce DB or leftover cell |
| Trade-off analysis | Paper JSON vs optional Bedrock; hold/rollback vs bounce; why 5xx-quiet still pages | Mentions rollback or schema | Treats Bedrock as required |
| Security / reliability | Avery late 201 named; no PAN / `BAYPAY_DB_PASSWORD` in JSON or prompt | Mentions merchant delay | Secrets or PAN in the fixture |
| Communication | Rate + P99 + 5xx-not-the-page; does not announce a DB outage | Usable, slightly over-confident | “Database is down” in comms |
| Efficiency | 45–60 minutes; no live Bedrock/AWS required | Complete but slow | Incomplete JSON or paid apply to “summarize” |

Stabilization that only says “bounce the pool” while the excerpt shows Hikari pending **0** loses Production awareness.

**Pass guideline:** weighted score ≥ 70, student quotes **rate and P99**, withdraws or weakens “database is down” with a **file quote**, four buckets + `humanApproval` not auto-approved, no database or `dmgr-east` bounce. Live Bedrock neither raises nor lowers the score.
