# INTERVIEW-1601 — Instructor solution

**Do not share this file with students before they submit two-maturity drafts for 3–5 bank ids.**

Practice mode is **write first, reveal later**. The bank `--reveal` fields are a self-check. This folder is method, not a script to recite. Do not require a BayLearn UI, Bedrock, or AWS apply.

A single memorized paragraph in both maturity boxes must **not** max Technical accuracy or Diagnostic method.

## What “done” looks like

- Command: `python3 interview-bank/simulator.py --mode practice` (or `--id` / `--domain`). **No** `--reveal` on the first run.
- **3–5** real `AEJE-IQ-*` ids, at least two domains.
- Each id: **Engineer** plus **Senior or Staff** that differ in scope (mechanism vs trade-off / owner / refusal).
- **One** timed row: **8 minutes**, same bar (`--mode timed-interview` or a student clock).
- Avery Chen `11111111-1111-1111-1111-111111111111` or payment `c1601a11-0000-4000-8000-111111111601` named at least once.
- After drafts: optional reveal and a **gap list** (missed, over-claimed, will-not-copy). Pasting `engineerAnswer` back as the spoken answer is a fail.

## Maturity shape (acceptable, any id)

**Engineer.** Names the BayPay mechanism on `POST /api/v1/payments` (JMM, heap vs container limit, task role vs execution role, Actuator, idempotency — as the stem requires). Names one measurement. Refuses PAN on a label and leftover `dmgr-east` as the serving plane when relevant.

**Senior / Staff.** Same stem. Adds who decides this quarter, a trade-off (ECS apply default vs EKS API, 99.9% operated SLO vs 99.99% architecture goal), and an explicit **will not** (no NAT/EKS apply in a 90-minute answer, no TLS-off, no proven RCA without a file).

**Not acceptable.** Two boxes that differ only by the word “Staff.” A Bedrock dump. Reveal-first notes.

## Timed variant

Quality bar does **not** drop. Length may. A finished Engineer + a partial Senior with `timed: yes, 8:00` outscores an untimed paste of the bank key.
