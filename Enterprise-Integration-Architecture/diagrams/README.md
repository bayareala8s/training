# Required course architecture diagrams

Use this notation consistently:

- **Solid arrow** — synchronous request/reply
- **Dashed arrow** — asynchronous message or event
- **Cylinder** — durable store (DB, queue, bucket)
- **Hexagon** — adapter / ESB / tool gateway
