# `tools/` — not student-facing

These scripts generated the first draft of lessons and some lab docs.

**Students:** ignore this folder. Follow `GETTING_STARTED.md`, `labs/`, and `scripts/validate_lab.py`.

**Instructors:** do not run generators against a live cohort workspace. They can overwrite markdown. Lab Terraform and `scripts/validate_lab.py` are maintained by hand and must stay that way.
