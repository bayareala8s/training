# Principal Interview Cheat Sheet

> Scaffolded — content will be populated across all phases.

## Answer Structure

1. Restate the problem
2. State assumptions
3. Present architecture
4. Deep dive on critical path
5. Discuss failures and tradeoffs
6. Summarize decision criteria

## Red Flags to Avoid

- Universal best-practice claims
- Ignoring partial failure
- No quantitative reasoning
