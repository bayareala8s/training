# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.2.0] - 2026-07-25

### Added

- **140 curriculum chapters** across all 30 domains (~600k+ words)
- **25 system design exercises** with full 10-phase methodology
- **16 hands-on labs** with README, architecture, requirements, stubs, tests, Docker
- **16 production case studies** (DynamoDB, Kafka, Spanner, Stripe, Netflix, etc.)
- **145 principal-level interview questions** in YAML question banks
- **7 company interview guides** (Adobe, Amazon, Google, Microsoft, NVIDIA, Snowflake/Databricks, OpenAI/Anthropic)
- **Behavioral and mock interview modules** with scoring rubrics
- Expanded glossary (110+ terms), decision frameworks, and reading list
- Comprehensive sidebar navigation for all domains

[0.2.0]: https://github.com/hbhadra/principal-architect-knowledge-system/releases/tag/v0.2.0

## [0.1.0] - 2026-07-24

### Added

- Initial repository scaffold (Phase 0)
- Docusaurus TypeScript documentation site with Mermaid support
- Cursor rules, prompts, and agent definitions
- Content templates (chapter, lab, case study, system design, ADR, and more)
- Curriculum, skills matrix, study plan, and interview-readiness metadata
- Start Here section with 12-week learning path
- Validation scripts for frontmatter, links, and content coverage
- GitHub Actions CI pipeline
- Architecture Decision Records (ADRs 0001–0004)
- Linting configuration (Markdownlint, ESLint, Prettier, CSpell)

[0.1.0]: https://github.com/hbhadra/principal-architect-knowledge-system/releases/tag/v0.1.0
