# Architecture Review Prompt

Review the architecture described in [FILE OR DESIGN].

Act as a Senior Principal Architect conducting a formal architecture review.

Evaluate requirements, assumptions, scalability, availability, consistency, durability, failure modes, multi-region behavior, security, observability, operability, deployment, cost, compliance, and organizational ownership.

For every issue: assign severity, explain impact and likelihood, recommend mitigation.

End with executive summary, approval recommendation, and prioritized action plan.
