# Contributing (Cohort & Instructors)

## For students

1. Fork or branch per your cohort instructions.
2. Complete labs in weekly order; each week README lists deliverables.
3. Open pull requests using the default PR template.
4. Never commit AWS credentials, `*.tfvars` with real values, or state files.

## For instructors

- Customize `starter-templates/` and week READMEs for your AWS org constraints.
- Pin Terraform version in cohort repos via `.terraform-version`.
- Use GitHub Environment protection rules for `apply` jobs in Week 4+.

## Repository maintenance

- Keep syllabus in sync with `docs/syllabus.md` and `weeks/*/README.md`.
- Update capstone rubric in `capstone/README.md` if grading criteria change.
