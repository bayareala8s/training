# Week 1 — Enterprise Infrastructure as Code Foundations

| | |
|---|---|
| **Duration** | 8–9 hours (3h lecture · 4h labs · 1h assignment/review) |
| **Difficulty** | Intermediate foundation |
| **Prerequisites** | Basic AWS, Linux, Git, networking |

## Module summary

Week 1 establishes why enterprises adopt Terraform, how it differs from ad-hoc scripting and CloudFormation-only shops, and the non-negotiable practices for **state**, **backends**, and **repository structure**. Students bootstrap a production-style remote state backend and deploy a baseline environment.

## Deliverables

- [ ] Enterprise Terraform repository layout documented
- [ ] S3 + DynamoDB remote backend operational
- [ ] Dev environment deployed with remote state and course tags
- [ ] Assignment: IaC maturity assessment (see `05-assignment.md`)
