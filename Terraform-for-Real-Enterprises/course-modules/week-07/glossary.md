# Week 7 — Glossary

| Term | Definition |
|------|------------|
| **Least privilege** | Granting minimum permissions required for a task |
| **Permission boundary** | IAM maximum permissions cap for a role/user |
| **OIDC** | OpenID Connect; federated trust for CI without static keys |
| **Static analysis** | Scanning code/config without executing infrastructure changes |
| **Checkov** | Policy-as-code scanner for IaC misconfigurations |
| **tflint** | Terraform linter for style and provider-specific issues |
| **Policy-as-code** | Machine-readable policies enforced in CI or platforms |
| **SCP** | Service Control Policy—Organizations guardrail on accounts |
| **ABAC** | Attribute-Based Access Control using tags/attributes |
| **default_tags** | Provider-level tags applied to supported resources |
| **Sensitive variable** | Input redacted in logs; still protect state |
| **Exception process** | Formal workflow to accept a security finding temporarily |
| **SOC2** | Audit framework; controls often mapped to IaC evidence |
| **Shift-left** | Finding issues earlier in SDLC (PR vs prod) |
| **Guardrail** | Preventive control limiting insecure configurations |
