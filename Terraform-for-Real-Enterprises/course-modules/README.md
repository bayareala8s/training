# Course Modules — Terraform for Real Enterprises

**BayAreaLa8s** · 8 weeks · 64–72 hours · Intermediate to Advanced

This directory contains the **complete professional module content** for each week: detailed lectures, labs, assignments, knowledge checks, instructor notes, and glossaries.

## How to use these modules

| Audience | Start here |
|----------|------------|
| **Students** | Each week's `README.md` → follow lectures, then `labs/` |
| **Instructors** | `06-instructor-notes.md` + [instructor/INSTRUCTOR-GUIDE.md](../instructor/INSTRUCTOR-GUIDE.md) |
| **Self-paced** | Work sequentially week 1 → 8; submit assignments per rubric |
