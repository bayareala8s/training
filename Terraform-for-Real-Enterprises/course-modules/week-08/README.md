| | |
|---|---|

| **Prerequisites** | Weeks 1–7 complete |

## Module summary

Week 8 is the **integration capstone** for BayAreaLa8s Terraform for Real Enterprises. Students choose one of four tracks (landing zone, shared services, multi-region DR, or internal Terraform platform), deliver production-style Terraform with CI/CD, and present architecture, security, and cost outcomes. Full option details and evaluation rubric: [`../../capstone/README.md`](../../capstone/README.md).

## Deliverables

- [ ] Capstone repository with remote state and modules
- [ ] CI/CD pipeline (plan on PR, gated apply)
- [ ] Architecture diagrams + security review + cost analysis
- [ ] Final presentation (15–20 min) per cohort schedule
