# Week 8 — Instructor Notes

## Pre-class checklist

- [ ] Students selected capstone option (form or spreadsheet)
- [ ] Review [`../../capstone/README.md`](../../capstone/README.md) rubric with class
- [ ] Schedule presentation slots (15–20 min + 5 min Q&A each)
- [ ] Confirm AWS budget / lab-stop reminder
- [ ] Peer review rubric distributed (optional)

## Week structure (suggested)

| Day | Instructor activity |
|-----|---------------------|
| 1 | Kickoff lecture; office hours for scope |
| 2–5 | Async build; daily standup optional (15 min) |
| 6 | Dry-run presentations (cohort pairs) |
| 7 | Final presentations + peer review |

## Timing adjustments

| If cohort is 1 week only | Focus |
|--------------------------|--------|
| Narrow scope | Option 4 or simplified Option 2 |
| Require | CI plan + README + diagram minimum |

| If cohort has 2 weeks | Add |
|-----------------------|-----|
| Mid-week architecture review | 10-min per team |
| Security office hour | Checkov + IAM |

## Presentation coaching

- Require **backup recording** or screenshots
- Discourage live prod apply—dev/test only
- Rubric self-score due 24h before present

## Common student mistakes

| Mistake | Teaching moment |
|---------|-----------------|
| Toy single-account with no CI | Rubric “Needs work” on ops |
| Secrets in Git for “speed” | Automatic security cap |
| Scope creep (full landing zone + DR + platform) | Scenario quadrant slide |
| No cost section | Finance question in Q&A |

## Grading notes

- Use capstone rubric 2–4 scale consistently
- Weight **integration** over AWS service count
- Partial credit for excellent docs with incomplete demo if recording shows plan

## Demo failure contingency

If live demo fails, student may walk through recorded plan output—max score Docs & demo: 3 not 4 unless recovery is professional.

## Post-course

- Remind bootstrap bucket destroy order
- Survey link for course feedback
- LinkedIn/portfolio optional session

## Accessibility

- Allow pre-recorded presentations with live Q&A
- Caption recordings for async cohorts
