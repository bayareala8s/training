# Week 8 — Glossary

| Term | Definition |
|------|------------|
| **Capstone** | Integrative final project demonstrating weeks 1–7 practices |
| **Landing zone** | Multi-account AWS foundation with guardrails and shared services |
| **Shared services** | Central platform (network, logging) consumed by workload accounts |
| **Active-passive DR** | Primary region serves traffic; secondary standby for failover |
| **Golden path** | Documented standard workflow for teams consuming platform modules |
| **Module library** | Versioned collection of approved Terraform modules |
| **Self-assessment** | Student scoring against capstone rubric with evidence |
| **Peer review** | Structured feedback using same rubric criteria |
| **Integration demo** | Presentation showing CI, state, security, and ops together |
| **Scope management** | Limiting capstone breadth to deliver working, reviewable solution |
| **Tabletop** | Discussion-based DR exercise without full failover execution |
| **Cost analysis** | Estimate or allocation model for capstone resources |
| **Security review** | Document covering IAM, encryption, exposure, secrets |
| **Technical debt** | Conscious shortcuts documented for phase 2 remediation |
